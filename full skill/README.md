## Comment utiliser cette bibliothèque ?
L'Agent Orchestrateur lit le besoin, désigne l'Agent spécialisé, et ce dernier navigue directement dans les dépôts complets de sa catégorie pour trouver les fichiers, scripts et templates dont il a besoin.
